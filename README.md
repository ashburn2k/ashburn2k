## Private Work

A lot of the useful work is private by design: client projects, internal systems, local tools, and experiments that should not publish repo names or source.

GitHub can still show anonymized private activity in the contribution graph when private contribution visibility is enabled. That shows the activity signal without exposing repository names, commit details, or code.

## How I Like To Build

- Start with the real folder, route, data source, or runtime
- Keep changes update-safe and easy to roll forward
- Prefer small automation that removes repeated decisions
- Leave behind concise docs that make the next step obvious
